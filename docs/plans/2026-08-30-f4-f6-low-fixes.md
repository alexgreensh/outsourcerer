# Fix cycle 2, F4 F6 and LOW Findings Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Close the P0 F6 effort-relaunch regression, the two F4 lifecycle gaps, and the three cheap LOW findings while keeping every regression test and the conformance gate honest.

**Architecture:** Preserve the pane-shell PID as the tmux endpoint identity, and add a separately recorded engine-child PID plus start identity for lifecycle supervision. Reaping, heartbeat activity, fleet observations, and endpoint re-proof use the engine identity when available, falling back conservatively to the pane's foreground command for older records. All interactive relaunches use the existing launch finalizer, and a verified control exit writes an idempotent terminal registry event.

**Tech Stack:** Bash 3.2-compatible shell, tmux, jq, POSIX tools, shell regression suites in `plugins/outsourcerer/skills/outsourcerer/scripts/tests/`.
